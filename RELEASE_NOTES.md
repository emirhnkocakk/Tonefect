## What's new / Yenilikler

- 🔔 **In-app updates** – Grainline now tells you when a new version is out and can download and install it for you (Settings → About → Check for updates).
  / **Uygulama içi güncelleme** – Yeni sürüm çıkınca Grainline seni uyarır ve tek tıkla indirip kurar (Ayarlar → Hakkında → Güncellemeleri denetle).
- ⚙️ Settings menu, smart alignment guides, Grainline branding (from earlier versions).
  / Ayarlar menüsü, akıllı kılavuz çizgileri, Grainline markası (önceki sürümlerden).

Install: run `Grainline-Setup.exe`. / Kurulum: `Grainline-Setup.exe` dosyasını çalıştır.
